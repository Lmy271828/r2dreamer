# 消融实验设计：分层向量动作头 vs 分层类别动作头

> 约定（2026-10-30 定）：凡有消融价值的修改，先写进本文档（假设/对照/判据），
> 再在代码里预留模块开关（默认关、指向本文档），然后继续主设计。
> 消融实验的启动时机由"主设计推进到该改动的收益变大的阶段"决定，不阻塞主线。

## 状态：RESERVED（模块已预留，未排期）

主设计当前是**分层类别头**（Arm A），它就是主线本身；本文档定义的是它的
第一条正式消融对照（Arm B），以及未来所有动作头消融共用的一套规程。

## 1. 研究问题

在「槽位选择 × 格位选择」的两级动作结构下，格位这一级的表示形式：

- **Arm A（主线，现状）**：格位 = 576 路类别分布（placement_mask 硬掩码）。
- **Arm B（对照）**：格位 = 二维连续分布（tan-h 界定的对角高斯，输出归一化
  坐标 [0,1]²，环境边界处离散化到 18×32 格）。

**假设 H1**：连续格位头让"相邻格等价"的归纳偏置显式化（类别头把 (9,16) 和
(9,17) 当作两个无关类别），在放置精度敏感的对局（桥牌位、拉扯距离）上样本
效率更高。
**假设 H2（反方）**：类别头的硬掩码在合法性利用上占优；连续头的"投影到最近
合法格"会引入边界梯度偏差与掩码失配，抵消归纳偏置收益。

两者的槽位级（6 路 categorical，含 ABILITY 位）完全相同——卡牌身份本质离散，
不在本实验变量内。

## 2. 控制变量

| 维度 | 规程 |
| --- | --- |
| 共享组件 | encoder / RSSM / reward / cont / value / buffer / 采集管线逐字节相同；仅 actor 格位头不同 |
| 参数量 | 两臂 actor 参数量对齐到 ±5%（B 臂增删一层 cell MLP 补偿高斯参数） |
| 探索预算 | A 臂初始均匀分布的有效格位 σ ≈ 0.29（归一化坐标下 1/√12）；B 臂 σ0 设为同值，两臂 act_entropy 系数相同，另外各自报告各自熵（不可直接比，只看轨迹形状） |
| 合法性 | A：硬掩码（-1e9 洪泛）。B：采样后投影到最近合法格（掩码期望 E_mask 的最近邻），env 边界做，**投影本身是 B 臂的固有属性而非缺陷**（对应真实连续控制器的离散执行层）；log_prob 报投影前连续值，另记投影率（被改动的动作占比）作为 B 臂专属指标 |
| 数据 | 两臂喂同一 seed 序列的引擎对局；自博弈种子随机化已保证对局多样性，无需配对 |
| 种子 | 首轮每臂 2 seeds；若两臂差 < 判据阈值但方向一致，补第 3 seed |
| 预算 | 单实例 fps≈3，每臂每 seed 100k step ≈ 9h；首轮 4 run ≈ 1.5 天（可串行） |

## 3. 指标与判据（预注册，防事后找补）

主指标（样本效率）：**step 数达到对脚本对手胜率 60%**（先到者赢）。
辅指标：
- episode/score 对 step 的斜率（前 100k step 线性拟合）；
- 格位使用多样性：每局使用的不同格数（B 臂预期更高，若反而更低则 H1 直接否证）；
- 投影率（仅 B）：>40% 说明连续头大量输出非法位，掩码失配主导，H2 赢；
- action_type_share（wait/play/ability 三桶）；
- slot 熵塌缩时点（两臂应一致，否则说明差异来自槽位级噪声而非格位级，实验作废重跑）。

判定：
- B 在主指标上快 ≥20% 且辅指标方向一致 → H1 成立，格位连续化进主线（A 保留
  为 config 选项）；
- 差 <10% 或方向矛盾 → 维持 A，文档记"该改动收益不足以偿付实现与掩码复杂度"；
- B 显著差 → 关闭该方向，标注"已消融，勿重提"，除非世界模型升级（如格位
  重建头出现）使前提改变。

## 4. 已知混杂（两臂共有，不影响对比但影响绝对结论）

圣水通道为探针真值（非部署保真）；想象 rollout 手牌/掩码冻结近似；±1 稀疏
终局奖励导致低分辨力（这也是判据用"先到 60%"而非均值差的原因）；对手为脚本
策略而非自博弈池（M5 后需复测一次）。

## 5. 模块预留（已实现）

`CardActionHead(..., cell_head=...)`：
- `"categorical"`（默认，= Arm A，主线行为，无任何额外开销）；
- `"gaussian"`（= Arm B，抛 NotImplementedError，指向本文档）。
排期实现 B 臂时：新增 `GaussianCellHead`（输出 μ,logσ → tanh 界定对角高斯），
env 侧新增"最近合法格投影"边界函数，扁平动作接口不变。
