## 1. 研究问题

M5 训练数据的卡组采样有两种对称性实现：

- **Arm A（主线，现状）**：`deck_mode=random`，每局 deck0/deck1 独立
  均匀抽 8 卡。方向对称性（deckA 打 deckB 与反向）**在期望中成立**，
  但相邻局不配对——同一 matchup 的两个方向出现在不同 seed、不同对手
  状态下。
- **Arm B（消融）**：奇偶局成对换边——第 2k 局抽 (dA, dB, seed)，
  第 2k+1 局强制同 seed + `_swap_next`，得 (dB, dA, seed)。同一
  matchup 的两个方向在**相同 dynamics、相同运气**下成对出现。

价值公式（动机）：成对使

  A⁽¹⁾ = R⁽¹⁾ − V(s, dA, drop(dB)) 与 A⁽²⁾ = R⁽²⁾ − V(s, dB, drop(dA))

的运气噪声严格对消，仅剩卡组角色差异——advantage 信噪比上升，critic
的零和对称结构 V(s,dA,dB) ≈ −V(s',dB,dA) 被直接写进训练对。

## 2. 已知代价（B 的假说风险）

- **卡组覆盖多样性减半**：相邻两局共享同一对卡组，单位 step 的不同
  (deck0,deck1) 组合数约降一半——可能拖慢世界模型对卡组动力学的覆盖
  （P0-P3 的覆盖目标）；
- **对手非平稳性增强**：自博弈下，成对的第二局面对的是"看过第一局"
  之后的快照/策略（若 refresh 恰在两局之间），配对纯净度受损——实现时
  refresh 必须落在偶数局边界；
- 与 league PFSP 采样的交互：未来对手池加权时，成对结构使权重语义从
  "单局" 变为 "matchup 对"，league_stats 需按对聚合。

## 3. 控制变量

| 维度 | 规程 |
| --- | --- |
| 共享 | 观测/动作头/世界模型/超参逐字节一致，仅卡组采样器不同 |
| 样本量公平 | B 的每步信息量更高但多样性更低——用**相同 step 数**对比（不用对局数） |
| 种子 | 每臂 2 seeds（两臂共 4 run），必要时各补 1 |
| 时机 | M5 快照对手激活且 score MA20 走平之后（避免热身期噪声混入） |
| refresh 对齐 | B 臂 refresh 只允许发生在偶数局边界 |

## 4. 指标与判据（预注册）

主指标：**value 零和一致性误差**
  E = |V(s,dA,dB) + V(s',dB,dA)| 的运行均值（由换边评估器在固定
  matchup 集上测量）。B 预期显著更低——这是换边直接训练的量。
辅指标：
- matchup 排序稳定性：eval_swap 成对优势对 (dA,dB) 排序的 bootstrap
  重采方差（M6 元分析的输入质量）；
- adv_std 轨迹（B 预期更早脱离 1e-4 量级）；
- score MA20 斜率（学习速度）；
- **世界模型覆盖哨兵**：`loss/dyn` 与卡组条件重建误差——若 B 的
  dyn 损失劣化 >15%，多样性代价坐实，即使主指标赢也要权衡。

判定：
- B 主指标优 ≥30% 且 dyn 哨兵未触发 → 换边进主线训练采样器；
- 优 10–30% → 只在 M6 元分析前的微调阶段启用（"分析前微调"档，
  呼应计划 v2 的收敛门禁）；
- 差 <10% 或 dyn 哨兵触发 → 维持 A，文档记录关闭该方向。

## 6. 下次实验（B 臂主线）设计与重点指标

### 实验设计
- B 臂 run：`deck_mode=random_paired`（已切 yaml），其余配置与
  1030_132316（A 臂）逐字节一致——两臂对比 = 两个 run 的同 step 对照；
- 配对周期与快照刷新对齐：refresh 间隔 30 局为偶数，落在配对边界
  （pair k = 第 2k-1/2k 局），保证每对两局面对同一快照版本；
- 覆盖审计：env 每 25 局打印 deck pair-hash 与排序卡组（console），
  离线统计 unique pair 数做覆盖哨兵。

### 重点观察指标（按优先级）
1. **世界模型覆盖哨兵**：`train/loss/dyn` 与 A 臂同 step 对比——劣化
   >15% 即覆盖多样性代价坐实（§4 判据），需要权衡；
2. **adv_std 演化**：走出 1e-4 量级的时间 vs A 臂（B 预期更早——配对
   去噪）；
3. **score MA20 / 局长**：学习速度不得差于 A 臂（换边是去噪手段，
   不是以学习速度换一致性）；
4. **action_type 演化**：与 A 臂同 step 对照（play 爬升斜率）；
5. 自博弈既有指标：快照激活后对手胜率趋 50%、局长变长（M5 验收
   顺延到本 run）。

### 暂不可测项（诚实边界）
§4 的主指标"零和一致性误差"需要**条件化 value**（S4 DeckEncoder），
S4-lane 激活前该指标缺位——本实验阶段以 1-5 项代理；S4 落地后可对
两臂 checkpoint 回测补测。
